# Homebase dashboard

A Home Assistant dashboard (Home, Sky and Fitness views) built from button-card templates.

Needs the HACS cards button-card, card-mod, apexcharts-card and layout-card. Copy the folders into
`/config`, merge `configuration.snippet.yaml`, and fill in `secrets.yaml` from `secrets.example.yaml`.
Change the entity ids to your own.

This dashboard was built with the help of AI.
